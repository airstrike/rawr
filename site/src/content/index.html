rawris rust augmented with rust

A Rust interpreter for your dev builds.

Mark a file with // rawr. rawr run interprets it, and Cargo compiles it for release.

Get started Try it in the browser

Interpret your crate while you develop

rawr run checks names, types and traits, then interprets. Code that fails the check doesn’t start.

Unmarked modules and dependencies are native, built by Cargo.

cargo build --release ships no interpreter.

// `rawr run` interprets this file, and `cargo build` compiles it as
// ordinary Rust.

struct Greeting {
    name: String,
    times: i64,
}

impl Greeting {
    fn line(&self, count: i64) -> String {
        format!("{count}. Hello, {}!", self.name)
    }
}

fn main() {
    let greeting = Greeting {
        name: String::from("rawr"),
        times: 3,
    };
    for count in 1..=greeting.times {
        println!("{}", greeting.line(count));
    }
}

Hot reload in the app you already have

rawr has no framework of its own. Your app keeps its libraries.

A save reaches the running app, which keeps its state when it can. A save that fails the check prints its error, and the last good version keeps running.

Apps and libraries

Let your users change your app in Rust

Your app adds the rawr crate and loads rules its users write in Rust, with no rebuild. Here the interpreter ships in your release build.

Embed rawr
src/main.rsyour app
use rawr::{Engine, Exports};

#[derive(Clone)]
#[rawr::export]
pub struct Transaction {
    pub payee: String,
    pub amount: f64,
}

fn main() -> Result<(), Box<rawr::EvalAltResult>> {
    let mut bank = Exports::new("bank");
    bank.add::<Transaction>();
    let mut engine = Engine::new();
    engine.export(bank)?;

    let script = engine.load("rules.rs")?;
    let category = script.func::<(Transaction,), Option<String>>("category")?;
    let tx = Transaction { payee: "Blue Bottle Coffee".into(), amount: -4.5 };
    println!("{:?}", category.call(tx)?);
    Ok(())
}
rules.rsyour user’s rules
use bank::Transaction;

fn category(tx: Transaction) -> Option<String> {
    if tx.payee.contains("Coffee") { Some("coffee".into()) } else { None }
}

Pre-alpha

rawr supports part of Rust. The API Reference lists what works.

rawr needs Rust 1.95 or newer. rawr-import needs a Unix system and a Rust nightly, as Requirements explains.

The API and commands may change. Report bugs on GitHub.
