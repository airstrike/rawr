Patterns

Patterns, and the expressions that take them.

match

Literals, ranges, alternatives with |, guards and @ bindings. Every match must cover every case. A pattern on an imported enum moves, lends or copies the variant’s fields as Rust does; Imports describes how.

let n = 42;
let size = match n {
    0 => "none",
    1 | 2 => "few",
    3..=9 => "some",
    x @ 10..=99 if x % 2 == 0 => "many, even",
    _ => "many",
};
println!("{size}");

Destructuring

Struct, tuple, enum and slice patterns. .. matches the rest. A pattern matched through a reference binds references, as Rust’s default binding modes do. A member that is already a reference gets one more, so let (_, x) = &(1, &n); makes x a &&i64. A let _: T; with no value binds nothing, as in rustc.

struct Point {
    x: i64,
    y: i64,
}

let Point { x, .. } = Point { x: 1, y: 2 };
let (a, b) = (3, 4);
let v = vec![1, 2, 3];
if let [first, .., last] = v.as_slice() {
    println!("{first} {last}");
}
println!("{x} {a} {b}");
rawr run destructure.rs

Destructuring assignment

An assignment can take a tuple, array, slice, struct or tuple struct pattern on its left, as in Rust. The forms are (a, b) = (b, a);, [x, .., y] = arr;, S { f, .. } = s;, T(x, _) = t; and their nested forms. _ = value; evaluates the value and assigns nothing. The value on the right is evaluated first, and then the places on the left are assigned from left to right. Parentheses around a place leave it a place, so (x) = 1; assigns to x and (*r) += 1; adds to *r.

The errors are rustc’s. Assigning twice to a local not declared mut is E0384. A left side that is no place, as in (x + y) = 1, is E0070, and a compound assignment to one is E0067. A pattern that can fail, as Some(x) = opt;, is E0005.

struct Point {
    x: i64,
    y: i64,
}

let (mut a, mut b) = (1, 2);
(a, b) = (b, a);
let (first, last);
[first, .., last] = [1, 2, 3, 4];
let x;
Point { x, .. } = Point { x: 5, y: 6 };
println!("{a} {b} {first} {last} {x}");
rawr run assign.rs

if let, while let and let else

Let chains work as in Rust 2024, in if and in while.

fn parse(s: &str) -> i64 {
    let Ok(n) = s.parse::<i64>() else {
        return 0;
    };
    n
}

let (a, b) = (Some(1), Some(2));
if let Some(x) = a && let Some(y) = b && x < y {
    println!("{x} < {y}");
}

let mut stack = vec![1, 2, 3];
while let Some(top) = stack.pop() {
    println!("{top}");
}
println!("{} {}", parse("7"), parse("seven"));

A let whose pattern is an enum with one variant can’t fail, so it needs no else.

enum Wrapper {
    Named(String),
}

let value = Wrapper::Named(String::from("rawr"));
let Wrapper::Named(name) = value;
println!("{name}");

Loops

loop, while and for. Labels work, and break can carry a value.

let grid = vec![vec![1, 2], vec![3, 4]];
let found = 'search: loop {
    for row in &grid {
        for &cell in row {
            if cell > 2 {
                break 'search Some(cell);
            }
        }
    }
    break None;
};
println!("{found:?}");

Patterns on &mut

A binding through &mut is its part of the place it came from, as in Rust. A change through it is made in the place itself, and nothing is copied out. This holds in match, if let, while let, let and let else, in nested patterns, and for ref mut. It holds on a range of elements, as in if let [a, .., b] = &mut v[1..4], and on what get_mut, last_mut or iter_mut().find(..) gives. Behind a RefCell borrow or an imported type’s guard, each use of the binding goes through the guard, which copies its value.

&mut x of a local not declared mut is rustc’s E0596 at the borrow, with its suggestion to add mut. This holds whether or not the reference is used.

struct Point {
    x: i64,
    y: i64,
}

let mut points = vec![Point { x: 0, y: 0 }, Point { x: 5, y: 5 }];
for p in &mut points {
    p.x += 1;
}
if let Some(Point { y, .. }) = points.get_mut(1) {
    *y = 9;
}
println!("{} {}", points[1].x, points[1].y);
rawr run iter-mut.rs
