Patterns

Patterns, and the expressions that take them.

match

Literals, ranges, alternatives with |, guards and @ bindings. Every match must cover every case.

let n = 42;
let size = match n {
    0 => "none",
    1 | 2 => "few",
    3..=9 => "some",
    x @ 10..=99 if x % 2 == 0 => "many, even",
    _ => "many",
};
println!("{size}");
rawr run match.rsmany, even

Destructuring

Struct, tuple, enum and slice patterns. .. matches the rest.

struct Point {
    x: i64,
    y: i64,
}

let Point { x, .. } = Point { x: 1, y: 2 };
let (a, b) = (3, 4);
let v = vec![1, 2, 3];
if let [first, .., last] = v.as_slice() {
    println!("{first} {last}");
}
println!("{x} {a} {b}");
rawr run destructure.rs1 3 1 3 4

if let, while let and let else

Let chains work as in Rust 2024, in if and in while.

fn parse(s: &str) -> i64 {
    let Ok(n) = s.parse::<i64>() else {
        return 0;
    };
    n
}

let (a, b) = (Some(1), Some(2));
if let Some(x) = a && let Some(y) = b && x < y {
    println!("{x} < {y}");
}

let mut stack = vec![1, 2, 3];
while let Some(top) = stack.pop() {
    println!("{top}");
}
println!("{} {}", parse("7"), parse("seven"));
rawr run let-else.rs1 < 2 3 2 1 7 0

A let whose pattern is an enum with one variant can’t fail, so it needs no else.

enum Wrapper {
    Named(String),
}

let value = Wrapper::Named(String::from("rawr"));
let Wrapper::Named(name) = value;
println!("{name}");
rawr run irrefutable.rsrawr

Loops

loop, while and for. Labels work, and break can carry a value.

let grid = vec![vec![1, 2], vec![3, 4]];
let found = 'search: loop {
    for row in &grid {
        for &cell in row {
            if cell > 2 {
                break 'search Some(cell);
            }
        }
    }
    break None;
};
println!("{found:?}");
rawr run labels.rsSome(3)

Patterns on &mut

A binding through &mut is its part of the place it came from, as in Rust. A change through it is made in the place itself, and nothing is copied out. This holds in match, if let, while let, let and let else, in nested patterns, and for ref mut. It holds on a range of elements, as in if let [a, .., b] = &mut v[1..4], and on what get_mut, last_mut or iter_mut().find(..) gives. Behind a RefCell borrow or an imported type’s guard, each use of the binding goes through the guard, which copies its value.

struct Point {
    x: i64,
    y: i64,
}

let mut points = vec![Point { x: 0, y: 0 }, Point { x: 5, y: 5 }];
for p in &mut points {
    p.x += 1;
}
if let Some(Point { y, .. }) = points.get_mut(1) {
    *y = 9;
}
println!("{} {}", points[1].x, points[1].y);
rawr run iter-mut.rs6 9
