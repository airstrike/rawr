Play

How the playground and the ?play bot run a snippet. Both run plain Rust programs with the same limits.

The sandbox

A snippet has no files, no environment variables and no network. On the server each run is its own process, and that process starts with an empty environment.

The snippet usesWhat happens
include_str!("notes.txt")The snippet doesn’t compile. The error is cannot use `include_str!` here: ?play has no files.
include_bytes!("cat.png")The snippet doesn’t compile. The error is cannot use `include_bytes!` here: ?play has no files.
mod util;The snippet doesn’t compile, because there is no util.rs. The error is file modules require project/package compilation. An inline module, mod util { .. }, works.
env!("HOME")The snippet doesn’t compile. The error is cannot use `env!` here: ?play has no files. It has no environment variable `HOME` either.
std::fs, std::env, std::net or std::threadThe snippet doesn’t compile. rawr has none of these modules. The error for std::fs is unknown type `std::fs`.
use reqwest; or any other crateThe snippet doesn’t compile. The error is unknown import `reqwest`. A snippet that names iced or tokio gets a message instead.

The clock

A program reads the real clock. Real time counts against the time budget.

Output

The reply is the program’s stdout and stderr in the order it wrote them. Stderr shows in its own colour in the playground. The reply shows the exit status when it isn’t 0.

Limits

LimitValue
Time budget5 seconds of real time for a run on the server.
Whole run15 seconds. The process is stopped after that.
Memory256 MB of address space per run.
Operations1,000,000 per run on the server.
Call depth32.
Strings65,536 bytes.
Arrays, vectors and maps65,536 items.
Program output64 KiB. Longer output ends with … output truncated, and the program is stopped.
Discord reply2000 characters.
Runs in Discord4 a minute per user. 12 a minute per channel.
Runs in the playground6 a minute and 60 an hour per visitor.
Playground code16 KiB. A share can be up to 64 KiB.

In the browser a run has 10 seconds of real time. It has no operation limit there.

A run over the Discord rate limit gets an hourglass reaction instead of a reply. An edit over the limit is ignored.

Where ?play differs from rawr run

A snippet has no Cargo.toml, no files and no window.

Crates

A snippet can use rawr’s std and no crates. Use rawr run for a program that needs a crate.

Snippets that don’t run here yet

iced programs and async programs don’t run in the playground or in ?play yet. They will once generated bindings reach the bot and the browser. Until then such a snippet gets one message instead of a run. Use rawr run to run it on your own machine.

iced programs

A snippet is an iced program when it names the iced crate. It is one too when it uses a name from iced’s widgets and types without declaring or importing it. Those names are the ones a snippet could once use without a use, such as text, button, column, Color and Widget. A snippet that declares its own fn text is a plain program.

iced programs don't run here yet. They will once generated bindings reach ?play and the playground.

Async programs and tokio

A snippet is an async program when its main is async, as #[tokio::main] marks it. It is one too when it names the tokio crate.

async programs (`async fn main`, `#[tokio::main]`) don't run here yet. They will once generated bindings reach ?play and the playground.

Notes and replies

A note is a short line that comes with the reply.

Notes on program output

Note or lineMeaning
This iterator is never used. Iterators are lazy and do nothing unless consumed.The snippet’s last value is an iterator that nothing consumes. Its stages never ran. Add .collect::<Vec<_>>() or a for loop.
… output truncatedThe program wrote more than 64 KiB. It was stopped, and the output ends there.
… cut to fit DiscordThe output was longer than a Discord message. The reply shows its start.
exit status 1The program didn’t exit with status 0. Status 1 means main returned Err or a limit stopped it. Status 101 means it panicked.
(no output)The program printed nothing.
