Macros

rawr has a fixed set of built-in macros. macro_rules! isn’t supported yet.

Built-in macros

MacroNotes
println! print!Write to stdout.
eprintln! eprint!Write to stderr.
format!Builds a String.
write!Writes to a Formatter in a Display or Debug impl.
panic!Exits with status 101.
assert! assert_eq! assert_ne!Panic when the condition fails. They take an optional message.
debug_assert! debug_assert_eq!Behave as in a Rust debug build.
unreachable! todo! unimplemented!Panic when reached.
vec!vec![1, 2] and vec![0; n], where n is any usize. An array’s [0; N] takes a literal or a const.
matches!Takes a guard, as in matches!(x, Some(n) if n > 2).
concat! stringify!Expand to a string literal.
cfg!Tests the machine rawr runs on: target_os, target_arch, target_family, unix and windows, with not, all and any. No feature is on. #[cfg(..)] on a statement works the same way.
env!Reads an environment variable when the program is checked.
include_str! include_bytes!Read a file relative to the source file.
let n = Some(3);
assert!(matches!(n, Some(x) if x > 2), "n is {n:?}");
let os = if cfg!(target_os = "macos") { "mac" } else { "other" };
let zeros = vec![0u8; 4];
println!("{os} {zeros:?}");
rawr run macros.rsother [0, 0, 0, 0]

Format strings

Format strings follow Rust’s rules. Positional, numbered, named and captured arguments work. So do fill, alignment, width, precision, signs, radix, {:?}, {:#?} and {:x?}. A width, precision or sign on {:?} of an Option, a tuple, a Vec or a derived struct applies to each number, bool and () inside, as rustc passes its formatter down. Strings and chars inside ignore it. {:x?} writes each integer inside in hexadecimal.

let name = "rawr";
let w = 8;
println!("{name:>8}|{:^7}|{:08.3}", "mid", 3.14159); //     rawr|  mid  |0003.142
println!("{:>w$}|{:.*}", 42, 2, 1.5); //       42|1.50
println!("{:+} {:#x} {:#b} {:e}", 5, 255, 5, 1500.0); // +5 0xff 0b101 1.5e3
println!("{:?}", "tab\there"); // "tab\there"
println!("{:x?} [{:>4?}]", vec![10, 255], Some(1)); // [a, ff] [Some(   1)]
rawr run format.rs rawr| mid |0003.142 42|1.50 +5 0xff 0b101 1.5e3 "tab\there" [a, ff] [Some( 1)]
