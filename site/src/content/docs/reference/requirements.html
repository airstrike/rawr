Requirements

What each part of rawr needs, where it has been tested and what is planned.

Status

rawr is pre-alpha. Its API, commands and error codes may change.

rawr supports part of Rust. The Overview lists what works today. If rawr runs code with a different result than Rust, or rejects Rust it says it supports, report it on GitHub with a small reproduction.
