Requirements

What each part of rawr needs, which platforms work and what is planned.

Status

rawr is pre-alpha. Its API, commands and error codes may change.

rawr supports part of Rust. The Overview lists what works today. If rawr runs code with a different result than Rust, or rejects Rust it says it supports, report it on GitHub with a small reproduction.

One command installs prebuilt rawr and rawr-import:

curl -LsSf https://rawr.airstrike.fyi/install.sh | sh

The prebuilt rawr-import-driver is for nightly-2026-07-11. For another nightly, rawr-import builds a driver once, the first time a project uses that nightly, and keeps it in rawr’s home. The range’s end moves forward as nightly does: CI builds the driver on each day’s nightly and moves it to the newest one that works. Imports says how.

Each release on GitHub carries archives for macOS on Apple Silicon and Intel, Linux on x86_64 and aarch64, and Windows on x86_64. Start gives the other ways to install.

Platforms

rawr-import runs on 64-bit macOS and on 64-bit Linux.

On Linux it covers x86_64 and aarch64, with glibc or musl. The prebuilt Linux binaries need glibc 2.35 or newer. On musl, build from source.

Every change to rawr runs rawr-import on x86_64 Linux in CI, with a project that has a Cargo dependency.

rawr-import hasn’t been tried by hand on Linux yet. If it fails there, report it on GitHub.

Windows is best effort. The rawr command builds for it, and irm https://rawr.airstrike.fyi/install.ps1 | iex installs it. rawr-import isn’t built for Windows yet, so a program with dependencies doesn’t run there. No one has tried rawr on Windows yet. If it fails, report it on GitHub.

Other systems, such as FreeBSD, aren’t supported.

The MCP server’s window screenshot and its input tools need macOS. They need no Screen Recording or Accessibility permission.
