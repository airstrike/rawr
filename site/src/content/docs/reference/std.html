std

The parts of the standard library that rawr provides.

String and &str

push, push_str, insert, pop, remove, truncate, clear, trim, find, replace, split, splitn, split_whitespace, lines, chars, char_indices, bytes, as_bytes, starts_with, contains, to_uppercase, parse, String::from_utf8 and more. len counts bytes.

let line = "  id=7, name=rawr ";
let fields: Vec<&str> = line.trim().split(", ").collect();
let id: i64 = fields[0].replace("id=", "").parse().unwrap();
println!("{fields:?} {id}");
rawr run strings.rs["id=7", "name=rawr"] 7

Vec and slices

push, pop, insert, remove, swap_remove, retain, extend, dedup, sort, sort_by, sort_by_key, contains, windows, chunks, first, last, resize, resize_with, Vec::with_capacity and more. get_mut, first_mut, last_mut and iter_mut().find(..) lend an element to change.

struct Item {
    id: u32,
    n: u32,
}

let mut items = vec![Item { id: 1, n: 0 }, Item { id: 2, n: 0 }];
if let Some(item) = items.iter_mut().find(|i| i.id == 2) {
    item.n += 1;
}
items.retain(|i| i.n > 0);
println!("{} item, id {}", items.len(), items[0].id);
rawr run find-retain.rs1 item, id 2

Iterators

map, filter, enumerate, zip, skip, take, step_by, rev, any, all, position, fold, sum, max, min, count, collect and more. std::iter::once and std::iter::empty start one. An iterator can be cloned and walked again.

let words = ["one", "two", "three"];
let long: Vec<(usize, &str)> = words.iter().copied().enumerate().filter(|(_, w)| w.len() > 3).collect();
let total = (1..=10).step_by(3).fold(0, |acc, x| acc + x); // 22
println!("{long:?} {total}");
rawr run iterators.rs[(2, "three")] 22

Arrays

[T; N]::map gives a [U; N].

let squares = [1, 2, 3].map(|x| x * x);
println!("{squares:?}");
rawr run array-map.rs[1, 4, 9]

Numbers

abs, pow, sqrt, powi, powf, floor, round and kin. Floats also have sin, cos, tan, their inverses and hyperbolic forms, atan2, hypot, exp, ln, log, log10, to_degrees and to_radians. rem_euclid and div_euclid work on floats and integers. A number’s method can be called by its path.

let angle = 1.0_f64.atan2(1.0).to_degrees(); // 45.0
let wrapped = f32::rem_euclid(-0.25, 1.0); // 0.75
println!("{angle:?} {wrapped:?}");
rawr run floats.rs45.0 0.75

Duration and Instant

Duration::from_millis and its kin, as_secs, as_millis, as_secs_f64, Instant::now, elapsed and duration_since work. So do +, -, *, / and <. In an iced app, these are iced::time’s, which are std’s own.

use std::time::{Duration, Instant};

let start = Instant::now();
let step = Duration::from_millis(500) * 3;
println!("{step:?}"); // 1.5s
let spent = start.elapsed();
println!("{}", spent < step);
rawr run time.rs1.5s true

Futures

std::future::Future is the type of an async block and of an async fn’s result, written impl Future<Output = T>. Outside iced, it is a Rust future that the crate’s own runtime polls, as Run describes. tokio’s join! and the futures crate’s join! run two to five futures together and give their outputs as a tuple.

async fn double(n: u32) -> u32 {
    n * 2
}

#[tokio::main]
async fn main() {
    let pair = tokio::join!(double(1), double(2));
    println!("{pair:?}");
}
rawr run futures.rs(2, 4)

Collections

HashMap with the entry API, HashSet, BTreeMap and BTreeSet. A map’s get_mut lends a value to change. rustc_hash’s FxHashMap and FxHashSet are rawr’s HashMap and HashSet. Cargo still builds them with the crate’s hasher.

use std::collections::HashMap;

let mut counts: HashMap<&str, i64> = HashMap::new();
for word in "a b a".split(' ') {
    let n = counts.entry(word).or_default();
    *n += 1;
}
println!("a: {}, b: {}", counts["a"], counts["b"]);
rawr run hashmap.rsa: 2, b: 1

RefCell

new, default, borrow, borrow_mut, into_inner, replace, take and clone. A borrow ends with its block. A borrow that conflicts with one still held panics with Rust’s message.

use std::cell::RefCell;

let cell = RefCell::new(vec![1]);
cell.borrow_mut().push(2);
let len = cell.borrow().len(); // 2
println!("{len}");
rawr run refcell.rs2

std::mem and PhantomData

std::mem::swap, replace and take work. So does std::marker::PhantomData. Two fields or two tuple members of one value can be borrowed &mut at once, as in swap(&mut pair.0, &mut pair.1).

let mut a = vec![1];
let mut b = vec![2, 3];
std::mem::swap(&mut a, &mut b);
let old = std::mem::take(&mut a); // [2, 3], and a is empty
println!("{old:?} {a:?} {b:?}");
rawr run mem.rs[2, 3] [] [1]

fmt, ops and cmp

std::fmt for Display and Debug impls, std::ops for operator traits, and std::cmp::Ordering.

use std::cmp::Ordering;

let order = 3.cmp(&5);
assert_eq!(order, Ordering::Less);
println!("{order:?}");
rawr run ordering.rsLess

Conversions

From and Into between your own types, and from your own type into a number type. TryFrom between integer types. From::from, Into::into, Clone::clone, ToString::to_string, the methods of Option and Result, and your own associated functions all work as values.

struct Celsius(f64);

impl From<Celsius> for f64 {
    fn from(c: Celsius) -> f64 {
        c.0
    }
}

let names: Vec<String> = ["a", "b"].iter().map(|s| s.to_string()).collect();
let parsed: Vec<i64> = vec!["1", "x"].into_iter().map(|s| s.parse::<i64>()).filter_map(Result::ok).collect();
let byte = u8::try_from(300_i64); // Err
let degrees: f64 = Celsius(21.5).into();
println!("{names:?} {parsed:?} {} {degrees}", byte.is_err());
rawr run conversions.rs["a", "b"] [1] true 21.5

path, ffi, io, env and fs

std::path and std::ffi work in every program. PathBuf, Path, OsString and OsStr are Rust’s own types. Path is another name for PathBuf, and OsStr is another name for OsString. They have new, from, push, join, parent, file_name, file_stem, extension, display, to_str and to_string_lossy. An imported Rust function doesn’t take one yet.

std::io has Error and ErrorKind, with Error::new, Error::other, Error::from and kind. Nothing in it reads or writes a file.

std::io::stdin() reads the program’s standard input. read_line and read_to_string append to a &mut String and return an io::Result of the bytes read, as in Rust. lines() reads to the end of the input before it gives its first line, so a program that answers each line as it comes uses read_line. lock() gives the same reader. std::io::stdout().flush() flushes what the program printed.

std::env::args() gives the program’s arguments. Under rawr run the first is the program’s name and the rest come after --, as cargo run gives them. Run says more.

std::fs::read_to_string reads a file into a String. Snippets in the playground read no files.

use std::path::PathBuf;

let path = PathBuf::from("src").join("main.rs");
let ext = path.extension().unwrap().to_str().unwrap(); // "rs"
let err = std::io::Error::other("disk full");
println!("{} {ext} {:?} {err} {:?}", path.display(), path.parent(), err.kind());
rawr run path.rssrc/main.rs rs Some("src") disk full Other
