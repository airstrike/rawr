Commands

Every command you type as rawr .., and the extensions it hands programs to.

Paths

Most commands take an optional path. The path can be a crate directory, its Cargo.toml or a single .rs file. Without a path, rawr looks in the current directory and its parents for a crate with a marked file. The crate root is src/main.rs or src/lib.rs. The root or a module it declares must start with // rawr.

A single file runs with or without the marker. rawr runs its top-level statements and then calls fn main.

Commands of rawr

These come with rawr-cli, which needs Rust 1.95 or newer. rawr-cli also installs cargo-rawr, so cargo rawr run works the same as rawr run.

CommandWhat it does
rawr [run] [path]Checks a program and runs it. run is the default command, so rawr alone runs the crate in the current directory. Errors from cargo check are printed after a program that runs once. A program with Rust dependencies or native modules goes to rawr-import. An iced app goes there too, as iced describes.
rawr check [path]Checks a program without running it. It prints Checked and the entry path, or the first error. Then it runs cargo check and prints cargo check passed or rustc’s errors. It exits with status 1 if either check fails.
rawr new <path>Creates a Cargo crate with no dependencies. Its src/main.rs starts with // rawr and prints three lines. It refuses a path that holds files.
rawr new <path> --template <name>Creates a crate from a template that an installed extension offers. rawr new --help lists the templates. No extension offers one today.
rawr mcp [path]Runs an MCP server on stdio for coding agents such as Claude Code and Codex. Relative paths in its calls start at path, else the current directory. Installed extensions add tools to it. Agents describes it.
rawr init [--claude] [--codex] [path]Registers rawr mcp in the project’s agent config: .mcp.json for Claude Code and .codex/config.toml for Codex. Without a flag it looks for a .claude or .codex directory. It keeps the old file as .bak.
rawr doctor [path]Shows where rawr and each extension are and the program it finds. An extension that isn’t installed is shown with the commands that install it. Then it shows each installed extension’s own report, if it has one.
rawr -h, --helpPrints the help. For each installed extension it shows where it was found, which programs it serves and which commands it adds.
rawr -V, --versionPrints the version.

Set RAWR_VERBOSE=1 to see how a program was loaded and which binary ran it.

Commands from extensions

rawr runs run, check, new, doctor, mcp and init itself. It hands other commands to the installed extension that adds them. It looks for rawr-<name> binaries next to its own binary first and then on PATH.

  • rawr-import runs rawr run and rawr check for programs with Cargo dependencies or native modules. It adds no commands.

rawr preview and rawr snapshot came with rawr-iced, which is gone. rawr preview comes back as open work. Previews says more.

Exit status

  • 0 when the command succeeds.
  • 1 when a check fails or when main returns Err. rawr check also exits with status 1 when cargo check fails.
  • 101 when a program panics.

Files rawr writes

  • target/<host>/debug/ holds the compiled crates. rawr run and cargo build share them.
  • target/rawr/ holds rawr’s cached data and the generated runner. cargo clean removes it.
