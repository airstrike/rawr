Play

The playground runs Rust in your browser. A program shows its output.

The editor

Ctrl+Enter or Cmd+Enter runs the code.

The Examples menu lists plain Rust programs. Its Rustlings group holds solutions from rustlings, used under its MIT licence. Each one names the file it came from. A first visit opens the first example. The editor keeps your latest snippet, so /play opens where you left off.

The playground has the same limits as the bot.

Run in browser is the default. rawr loads into the page once the page is up, so it doesn’t hold up the first paint. A program shows its output as the server would. An edit runs the program again after a short pause.

Run on server runs the snippet on rawr’s server. A snippet goes to the server by itself when rawr doesn’t load in the browser. It also goes there when rawr itself stops on it in the browser, and the next run loads a fresh copy of rawr.

The address

The page’s address keeps what you picked. An example you load adds its name after a #, such as /play#word-count. Editing the code drops that name, because the code is no longer the example’s. Picking Run on server adds ?run=server. The browser is the default, so it adds nothing. Opening an address restores both. Picking an example or a mode replaces the address and doesn’t add to the browser’s history.

Share links

Share saves the code and gives a link of the form /play/<id>. The link keeps ?run=server when you picked the server. It never has an example’s name, because its code is the share’s. A share’s code also wins over an example’s name in an address. A shared link shows a preview card in Discord and other apps. The card shows the first line of the program’s output. A share that nobody opens for 30 days is deleted.

What runs

A plain program runs the way rawr run runs a file. The reply is its stdout and stderr in the order it wrote them.

A snippet of statements alone runs as the body of main. If its last expression has no semicolon, its value is printed with {:?}. Its locals drop at its end, as main’s do. A snippet that opens with an inner attribute, such as #![allow(dead_code)], is a file and runs as written.

let xs = vec![3, 1, 2];
xs.iter().sum::<i64>()
6

The reply shows the exit status when it isn’t 0.

A snippet that uses iced, or whose main is async, gets its message instead of a run.

What a snippet can reach

A snippet runs in a sandbox. It has no files, no environment variables and no network. It can use rawr’s std and no crates. The Play reference lists every limit and every difference from rawr run.
