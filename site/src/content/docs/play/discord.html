Discord

The ?play bot runs a Rust snippet posted in Discord and replies with the result.

In Discord

Write ?play on the first line of a message and put the snippet in a code block below it. The fence can be ```rust, ```rs or a bare ```. The bot also answers when ?play is in the fence’s info string, as in ```rust ?play.

Discord
?play 320x200 light msg=Message::Increment
```rust
column![text("hi"), button("go")]
```

The bot runs the first code block in the message. It reads a snippet the way the playground does. An error gets the report that rawr check would print.

If you edit a ?play message, the bot runs the snippet again and edits its reply.

Options

Options go on the ?play line after the command.

OptionMeaning
WxH or size=WxHThe canvas size in logical pixels. Each side can be from 1 to 2048. Without a size the canvas fits the content.
dark, light or theme=..The theme to render with. The default is dark. An app that passes its own function to .theme(..) uses its own theme.
msg=EXPR or message=EXPRA message to apply to an app. Repeat it to apply several in order.
mineOnly you can click the reply’s buttons. Without it anyone can click them.

Buttons

A reply to an app has a button for each widget you can click in its image. A button’s label is the widget’s text. A label that appears twice gets a number, as in + (2). A reply shows at most 20 buttons. When an app has more than 20 widgets to click, a menu under the buttons holds up to 25 more. Picking one from the menu clicks it, as its button would.

A button clicks its widget in the app, the way a mouse would. The bot runs the app again from the start, with its messages and every click so far, and edits its reply with the new image and new buttons. A line under the image lists the clicks. If a click starts an animation, the reply shows it as a GIF.

Anyone in the channel can click a reply’s buttons. To keep the clicks to yourself, add mine to the ?play line, as in ?play mine. Then anyone else who clicks gets a note that only they can see. The bot reads mine from the message as it is now, so an edit that adds or removes it takes effect on the next click.

Each click counts as a run against the clicker’s rate limits, which are 4 runs a minute per user and 12 a minute per channel. A click over a limit gets a private note that says when to try again. A click while the reply is still rendering is ignored. The app and all of its clicks share the still budget of 5 seconds.

A reply takes up to 24 clicks, and then its buttons go away. Edit the message to start over. An edit always starts the clicks over. A button on a reply whose message was edited since gets a private note to run it again.

Togglers, radio buttons and checkboxes get buttons too. Each is labelled by its own label. One without a label gets its number, as in #5. A click on its button toggles it or picks it.

A slider gets two buttons, Slider − and Slider +. Each moves the slider one step, as the down and up arrow keys do with the mouse over it. Two sliders get numbers, as in Slider + (2). A slider whose step is small needs many clicks to cross its range, and a reply takes 24.

A text input gets a button with a pencil, labelled by its placeholder. The button opens a small form with one text field. The text you send replaces what the input holds, and then the bot presses Enter in it. That counts as one click. A typed text shows in the line of clicks, except in a password field, where it shows as dots.

The text travels inside the reply’s buttons, so a reply only holds about 90 characters of typed text in all. The form says how much still fits. Once nothing fits, the buttons go away, as they do after 24 clicks. Don’t type a real password.

Adding the bot to a server

Use the invite link to add the bot to a Discord server you manage. The bot answers only in channels a moderator turns on. It doesn’t answer in direct messages.

Moderators choose the channels with the /play-channel command. It needs the Manage Channels permission in the channel it changes.

CommandWhat it does
/play-channel add [channel]Turns the bot on in a channel. The default is the current channel.
/play-channel remove [channel]Turns the bot off in a channel.
/play-channel listLists the channels where the bot answers.

A thread follows its parent channel. Running /play-channel add in a thread turns the bot on for the parent channel.

The status page shows whether the bot is up.
