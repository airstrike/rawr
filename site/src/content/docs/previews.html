Editor previews

A preview renders one view with the state you give it, without running the whole app. Nothing renders previews today.

The #[preview] attribute

#[preview] marks a view function to render on its own. The attribute comes from the rawr-macros crate. Its library name is rawr.

Cargo.toml
rawr-macros = { git = "https://github.com/airstrike/rawr" }

Write #[rawr::preview(..)], or use rawr::preview; and #[preview(..)]. Under Cargo the attribute leaves the item as written. Cargo doesn’t warn about a function that only previews use.
