Editor previews

A preview renders one view with the state you give it, without running the whole app. Nothing renders previews today.

The #[preview] attribute

#[preview] marks a view function to render on its own. The attribute comes from the rawr-macros crate, whose library name is rawr:

Cargo.toml
rawr-macros = { git = "https://github.com/airstrike/rawr" }

Write #[rawr::preview(..)], or use rawr::preview; and #[preview(..)]. Under Cargo the attribute leaves the item as written. Cargo doesn’t warn about a function that only previews use.

What renders them

Nothing does yet. rawr preview and rawr snapshot were removed with rawr-iced. rawr preview comes back on the plain runner as open work.

The VS Code extension is meant to show previews in a pane beside the code. Its pane has nothing to show until rawr preview returns.
