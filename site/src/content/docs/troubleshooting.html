Troubleshooting

Common errors and what to do about them.

First steps

  • rawr doctor shows where rawr and each extension are installed, and the program it finds.
  • RAWR_VERBOSE=1 rawr run says how the program was loaded and which binary ran it.
  • rawr --help lists the installed extensions and the commands each one adds.

“Its first line is not // rawr”

error[RAWR-ENVIRONMENT-MISSING-SOURCE]: `/home/you/app/src/main.rs` is not a Rawr file. Its first line is not `// rawr`, and no module it declares starts with it.
  = help: add `// rawr` as the first line of the crate root, or of a module it declares, to run it with Rawr

Add the line as the help says. A single .rs file runs without it.

After a shebang line or a frontmatter block, the marker goes on the next line. Run shows where.

“Not allowed in embedded manifests”

error[RAWR-ENVIRONMENT-PACKAGE-MANIFEST]: `lib` is not allowed in embedded manifests

A script’s frontmatter holds a table that cargo refuses in a script, and rawr refuses it with cargo’s message. Remove the table, or move the code into a Cargo package. Run says how rawr runs a script with dependencies.

A program needs an extension that isn’t installed

rawr run names the missing extension and prints the commands that install it. Imports and iced list them too.

RAWR-ENVIRONMENT-PROJECT-BUILD

The project’s toolchain is older than the Rust that rawr needs, which is 1.95. Update it with rustup update, or raise the version the project pins. The error can also name a Cargo config that sets a profile for the rawr crate. Imports explains how rawr builds a project.

rawr’s error or rustc’s?

rawr check prints rawr’s result first and rustc’s after it.

  • An error from rawr alone often means code that rawr doesn’t support yet. The error names the construct. The Overview lists the gaps.
  • An error from rustc alone means code that rawr accepts and rustc rejects. Fix it for rustc. The Overview lists those cases too.

The first run takes minutes

With dependencies or iced, the first rawr run compiles them and a runner. Later runs reuse that build. An edit to a marked file needs no native build.

The first project on a new toolchain or a new rawr also compiles rawr’s runtime, once for every project. rawr says so while it compiles. RAWR_RUNTIME_OPT_LEVEL=0 makes that compile faster, and scripts slower. Imports explains the runtime.

The first program on a machine that uses a crate also reads the crate’s API with rawr’s nightly, which builds the crate’s dependencies once more in check mode. Later projects that use the crate read it from rawr’s home instead. Imports explains shared bindings.

An iced app doesn’t pick up a save

A save that fails the check leaves the last good version running. The window shows the error and buttons to retry, copy the error or reset the app. Reload says what a reload keeps.

Reporting a bug

If rawr gives a different result than Rust, or rejects Rust it says it supports, report it on GitHub with a small reproduction.
