//A scripting language that reads like Rust

Rust Augmented With Rust

Rawr has Rust’s structs, enums, traits and match. It checks your code before running it and reports errors the way rustc does. Your program stays Rust. You write the parts you want to change while it runs in Rawr. Rawr code runs on an interpreter. Everything it calls into is native Rust.

The rawr crate is the language. Any Rust program can embed it. The rawr command runs Rawr programs. rawr-iced adds iced support. Install it and rawr hands programs that use iced to it. It reloads native iced apps in about 0.2 s.

Install Rawr See rawr-iced

//Parts

The crate, the command and rawr-iced

The rawr crate knows nothing about windows or widgets. It parses, checks and runs Rawr inside whatever Rust program embeds it.

The rawr command runs Rawr programs. rawr run cart.rawr runs once and exits.

rawr-iced adds iced support. Install it and rawr hands programs that use iced to it. rawr parses the program once. rawr-iced reads that parse and does not parse it again.

rawr crateThe language. Embed it in any Rust program. Pass source text to Engine::compile, then call a script function with call_fn. Builds on stable Rust 1.95 or newer.
rawr commandRuns and checks Rawr programs. Builds on stable Rust.
rawr-icedRuns programs that use iced. It adds:
  • reload on save in about 0.2 s
  • imports of your own Rust crates without bindings
  • #[preview] views and PNG snapshots
  • rendered frames from the ?play bot and the playground
examples/cart.rsthe host
//! Rawr embedded: Rust code running a Rust-shaped script.
use rawr::{Engine, Scope};

fn main() -> Result<(), Box<rawr::EvalAltResult>> {
    let engine = Engine::new();
    let ast = engine.compile(include_str!("cart.rawr"))?;
    engine.call_fn::<()>(&mut Scope::new(), &ast, "main", ())
}
cargo run --example carttotal: 27

//Install

Install from git

The language is an ordinary crate. It builds on stable Rust 1.95 or newer.

The rawr command builds on stable Rust too. It runs programs that don’t use iced.

rawr-iced needs more. It runs only on Apple Silicon Macs for now and needs nightly-2026-07-11 with the rustc-dev and rust-src components. Rawr also builds your own crates with that toolchain.

Embed the language

cargo add --git https://github.com/airstrike/rawr rawr

Then compile a file and call its main, as examples/cart.rs does above.

The rawr command

cargo install --locked --git https://github.com/airstrike/rawr rawr-cli

rawr-cli installs rawr. A program without iced runs once and exits. It doesn’t build anything or hot reload.

rawr-iced: toolchain, binary and import driver

rustup toolchain install nightly-2026-07-11 --component rustc-dev,rust-src
cargo +nightly-2026-07-11 install --locked --git https://github.com/airstrike/rawr rawr-iced-cli
cargo +nightly-2026-07-11 install --locked --git https://github.com/airstrike/rawr rawr-import --features rustc-driver

rawr-iced-cli installs rawr-iced. rawr-import installs rawr-import-driver in the same directory. The driver reads your Rust crates for imports. rawr finds rawr-iced next to itself or on PATH. cargo install builds iced into rawr-iced, so it takes a few minutes. After that, an iced app opens in seconds. A project with its own Rust crates compiles them on its first run.

Start an iced project

rawr new hello && cd hello && rawr run

With rawr-iced installed, rawr new writes a counter app to src/main.rawr. You don’t need a manifest until you add Rust crates. Edit it while the window is open.

//rawr-iced

iced apps that reload when you save

When your code uses iced, rawr brings in rawr-iced on top of the base language. It runs native iced apps written in Rawr. Rawr code uses the same impl Widget<Message>, column![] and match as iced master.

Save a .rawr file and rawr run reloads it in about 0.2 s. The window stays open and keeps its state.

//rawr-iced · Commands

Commands

rawr run, rawr check and rawr doctor come with rawr. The others come with rawr-iced. Every command takes a project directory or a single file. Run rawr --help for every option.

rawr runRuns a program once. A program that uses iced goes to rawr-iced, which opens the app. Saving a .rawr file reloads the app in place. Changing your Rust crates rebuilds them natively.
rawr checkType-checks without a window and reports errors the way rustc does.
rawr check --as-rustCopies the project under target/ with .rawr renamed to .rs and runs cargo check on it.
rawr previewOpens a view marked #[preview] on its own. ← and → step through a group.
rawr snapshotRenders every preview to a PNG. --check compares them with the committed images. --update replaces them.
rawr mcpAn MCP server that lets a coding agent list and render previews, run checks and screenshot the running window. Run rawr init --claude --codex to set it up for Claude Code and Codex.
rawr doctorReports on the environment and the project.

//rawr-iced · Rust imports

Import your own Rust crates without writing bindings

List a crate in rawr.toml and use it. Rawr reads only the Rust items your code uses. You can import custom iced widgets from your own crates.

gallery_ui::Dial is an ordinary iced Widget written in Rust. RawrGallery drives it from dial.rawr.

rawr.toml
[rust.dependencies]
gallery_ui = { package = "gallery-ui", path = "rust/gallery-ui" }
src/dial.rawr
use gallery_ui::Dial;

let face = container(Dial::new(self.value, Message::Turn).range(0..=100))
    .padding(LOOSE)
    .style(inset);

//rawr-iced · ?play

Render a snippet in Discord

In a Discord channel where the bot is turned on, write ?play over a code block with a view or a whole app, and it replies with the frame. The playground does the same in a browser. You don’t need to install anything.

Open the playground Add the bot to a server
Discord
?play 160x170 msg=Message::Increment
```rust
use iced::Center;
use iced::widget::{Widget, button, column, text};
// … the rest of the counter
```

rawr-play drew this counter after one Increment. The bot uses the same renderer.

//Status

Pre-alpha

The language crate and the rawr command build on stable Rust. rawr-iced runs only on Apple Silicon Macs. It follows iced master and pins one nightly. APIs, commands, file formats and error codes will change without notice.

Rawr doesn’t cover all of Rust yet. If it rejects valid Rust that it claims to support, that’s a bug. Please report it with a small reproduction.
