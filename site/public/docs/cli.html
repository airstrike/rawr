//Commands

Commands

You type every command as rawr ... The rawr binary runs some of them itself. It hands the rest to rawr-iced when rawr-iced is installed.

Paths

Most commands take an optional path. The path can be a crate directory, its Cargo.toml or a single .rs file. Without a path, Rawr looks in the current directory and its parents for a crate whose root file starts with // rawr. The root file is src/main.rs or src/lib.rs. If the root file of the crate doesn’t start with the marker, Rawr reports that its first line is not // rawr.

A single file runs with or without the marker. It may hold top-level statements. Rawr runs them and then calls fn main.

rawr --help lists the commands. When rawr-iced is installed, the help also shows where it was found and which commands it adds. rawr looks for rawr-iced next to its own binary first and then on PATH.

Commands of rawr

These come with rawr-cli and build on stable Rust. rawr-cli also installs cargo-rawr, which forwards to rawr. So cargo rawr run works the same as rawr run.

CommandWhat it does
rawr [run] [path]Checks a program and runs it. run is the default command, so rawr alone runs the crate in the current directory. A plain program runs once and exits. Then cargo’s errors from cargo check are printed, if there are any. A program that uses iced goes to rawr-iced. rawr-iced opens the app and reloads it on save. It runs cargo check in the background when the app opens and after each save.
rawr check [path]Checks a program without running it. It prints Checked and the entry path when the program is valid. It prints the first error when it isn’t. Then it runs cargo check on the crate. It prints cargo check passed or rustc’s errors. It exits with status 1 if either check fails.
rawr doctor [path]Reports on the environment and the project. It shows where rawr and rawr-iced are, their versions, the iced revision, the renderer, the project root, the entry file and the manifest.
rawr -h, --helpPrints the help.
rawr -V, --versionPrints the version.

Set RAWR_VERBOSE=1 to see how a program was loaded and which binary ran it.

Commands from rawr-iced

These need rawr-iced. With rawr-iced installed, it also runs rawr run, rawr check and rawr doctor for programs that use iced.

CommandWhat it does
rawr new <name-or-path>Creates a Cargo crate. It writes Cargo.toml, src/main.rs, rust-toolchain.toml and .cargo/config.toml. The last two make cargo build build as Rawr does, so both share one build of iced. src/main.rs starts with // rawr and holds iced’s counter. rawr run opens it and cargo run builds it natively.
rawr preview [path] [name]Opens one #[preview] view in a window. name is the preview’s name or group/name. Without a name it opens the last preview you picked. The arrow keys step through a group.
rawr snapshot --update [path]Renders every preview to a PNG under snapshots/ and replaces the stored images.
rawr snapshot --check [path]Renders every preview and compares it with the stored image. It exits with status 1 if any pixel differs. The new images go under target/rawr/snapshots/.
--verboseWith rawr snapshot, prints absolute paths and storage details.
rawr mcpRuns an MCP server on stdio for coding tools such as Claude Code and Codex. Its tools list and render previews, check the project and drive a running window. The window tools take screenshots, click, type, press keys, reset the app and wait for a reload.
rawr init [--claude] [--codex] [path]Registers rawr mcp in the project. --claude writes .mcp.json for Claude Code. --codex writes .codex/config.toml for Codex.
rawr cache cleanRemoves the shared builds that no running process uses.
rawr cache clean --allAlso removes the current project’s target/rawr.

Exit status

  • 0 when the command succeeds.
  • 1 when a check fails, when main returns Err or when a snapshot differs. rawr check also exits with status 1 when cargo check fails.
  • 101 when a program panics.

Files Rawr writes

  • snapshots/ holds the stored preview images. Commit it.
  • target/<host>/debug/ holds the compiled crates. rawr run and cargo build share them.
  • target/rawr/ holds Rawr’s cached data and the generated runner. cargo clean removes it. The images from the last rawr snapshot --check go in target/rawr/snapshots/.
