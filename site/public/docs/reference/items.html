Items

The items a program can declare.

fn

A function can be declared inside another function.

fn total(prices: &[f64]) -> f64 {
    fn cents(x: f64) -> f64 {
        (x * 100.0).round() / 100.0
    }
    cents(prices.iter().sum())
}

println!("{}", total(&[0.1, 0.2]));
rawr run nested-fn.rs0.3

struct

Structs with named fields, tuple structs and unit structs.

struct Point {
    x: f64,
    y: f64,
}
struct Meters(f64);
struct Marker;

let p = Point { x: 1.0, y: 2.0 };
let m = Meters(3.5);
let _marker = Marker;
println!("{} {} {}", p.x, p.y, m.0);
rawr run structs.rs1 2 3.5

enum

Unit, tuple and struct variants. A fieldless enum casts to an integer with as, and explicit discriminants set its values.

enum Shape {
    Empty,
    Circle(f64),
    Rect { w: f64, h: f64 },
}

enum Level {
    Low = 1,
    High = 10,
}

let n = Level::High as i32; // 10
let shape = Shape::Rect { w: 2.0, h: 3.0 };
if let Shape::Rect { w, h } = shape {
    println!("{n} {}", w * h);
}
rawr run enums.rs10 6

impl

Methods, associated functions and associated consts. An impl can sit inside a function body. Self works in a method’s type annotations.

impl Point {
    const ZERO: f64 = 0.0;

    fn origin() -> Self {
        Point { x: Self::ZERO, y: Self::ZERO }
    }

    fn shifted(&self, dx: f64) -> Self {
        let next: Self = Point { x: self.x + dx, y: self.y };
        next
    }
}

struct Point {
    x: f64,
    y: f64,
}

let p = Point::origin().shifted(2.5);
println!("{} {}", p.x, p.y);
rawr run impl.rs2.5 0

trait

Default methods, associated types and static functions. A trait can be implemented for your own types and for built-in types such as i64.

trait Describe {
    fn name(&self) -> String;

    fn describe(&self) -> String {
        format!("this is {}", self.name())
    }
}

impl Describe for i64 {
    fn name(&self) -> String {
        format!("the number {}", self)
    }
}

println!("{}", 7_i64.describe());
rawr run traits.rsthis is the number 7

Send and Sync

Every value in interpreted code is already Send and Sync, so these impls change nothing. rawr checks them as rustc does. impl Send without unsafe is an error, and so is an unsafe impl of another trait.

A bound such as T: Send, where T: Send + Sync or trait Job: Send is accepted, but rawr does not check it. rawr check runs cargo check, which does.

Every value in interpreted code is also sized, so a bound such as T: Sized asks nothing. A trait such as trait Space: Sized can’t be used as dyn Space, as in rustc.

struct Handle(u64);
unsafe impl Send for Handle {}
unsafe impl Sync for Handle {}

let h = Handle(7);
println!("handle {}", h.0);
rawr run unsafe-impl.rshandle 7

const and static

const LIMIT: usize = 10;
static GREETING: &str = "hello";

println!("{GREETING} {LIMIT}");
rawr run consts.rshello 10

type

Aliases can be generic. A pub type can be imported from another module.

type Pair<T> = (T, T);
type Grid = Vec<Vec<u8>>;

let p: Pair<i64> = (1, 2);
let g: Grid = vec![vec![0; 3]; 2];
println!("{p:?} {}x{}", g.len(), g[0].len());
rawr run aliases.rs(1, 2) 2x3

mod and visibility

mod util; loads util.rs or util/mod.rs beside the file that declares it. A module whose first line is // rawr is interpreted. Cargo builds a module without it as native Rust. Inline modules work too, also in a single file with no project, as in ?play and the playground.

pub, pub(crate), pub(super) and pub(in path) work. A path through crate:: or super:: reaches a name that a module brings in with use.

mod geometry {
    pub(crate) fn area(w: f64, h: f64) -> f64 {
        w * h
    }
}

fn main() {
    let a = geometry::area(2.0, 3.0);
    println!("{a}");
}
rawr run geometry.rs6

use

Paths, groups, and globs of a standard library module. A path that starts with :: names an outside crate, and its first name must be a crate. A glob of an enum’s variants, as in use Shape::*;, isn’t supported yet.

use std::collections::{HashMap, HashSet};
use std::fmt::*;
use ::image::ColorType;

#[derive]

Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash and Default. rawr checks a derive as rustc does, so deriving Copy on a struct with a String field is an error.

#[derive(Debug, Clone, PartialEq, Default)]
struct Order {
    id: u32,
    note: String,
}

let a = Order { id: 1, ..Default::default() };
let b = a.clone();
println!("{a:?} {}", a == b);
rawr run derive.rsOrder { id: 1, note: "" } true
