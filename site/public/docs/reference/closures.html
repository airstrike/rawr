Closures

Closures capture their environment, as in Rust.

closures.rs
fn apply(f: impl Fn(i64) -> i64, x: i64) -> i64 {
    f(x)
}

fn scale(k: i64) -> impl Fn(i64) -> i64 {
    move |x| x * k
}

fn main() {
    let mut log = Vec::new();
    let mut add = |line: &str| log.push(line.to_string());
    add("first");
    add("second");
    println!("{:?}", log);
    println!("{} {}", apply(|x| x + 1, 1), scale(3)(2));
    let odd_squares: Vec<i64> = (1..=10).filter(|x| x % 2 == 1).map(|x| x * x).collect();
    println!("{:?}", odd_squares);
}
rawr run closures.rs["first", "second"] 2 6 [1, 9, 25, 49, 81]

Captures

A closure that changes what it captures is FnMut. A move closure takes what it captures. A closure that moves a captured value out, as || drop(s) does, can be called once.

let mut count = 0;
let mut tick = || count += 1;
tick();
tick();

let name = String::from("rawr");
let greet = move || format!("hi, {name}");
println!("{count} {}", greet());
rawr run capture.rs2 hi, rawr

Passing and returning closures

A function takes a closure as impl Fn(..) or as a generic F: Fn(..). It returns one as impl Fn(..) or Box<dyn Fn(..)>. A struct field can hold a Box<dyn Fn(..)>.

struct Button {
    on_click: Box<dyn Fn() -> String>,
}

fn twice<F: Fn(i64) -> i64>(f: F, x: i64) -> i64 {
    f(f(x))
}

let b = Button { on_click: Box::new(|| String::from("clicked")) };
let four = twice(|x| x * 2, 1);
println!("{} {four}", (b.on_click)());
rawr run boxed-fn.rsclicked 4

Closures as values

A closure in a variable can be passed to a function, copied to another variable, or called from another closure. A closure that holds a value that is not Copy is not Copy, so let g = f; moves it. A parameter can be _ or another pattern.

let add = |(a, b): (i64, i64)| a + b;
let also_add = add;
let sums: Vec<i64> = vec![(1, 2), (3, 4)].into_iter().map(also_add).collect();
println!("{sums:?} {}", add((5, 6)));
rawr run copy-closure.rs[3, 7] 11

Parameter types

A closure’s parameters take their types from where it is passed.

#[derive(Clone, Copy)]
struct Color {
    r: f32,
    g: f32,
}

fn shade(f: impl Fn(f32) -> Color) -> Color {
    f(0.5)
}

let base = Color { r: 0.0, g: 1.0 };
let c = shade(|r| Color { r, ..base });
println!("{} {}", c.r, c.g);
rawr run struct-update.rs0.5 1

Async code

In an iced app, async fn, async blocks, async closures and .await work. iced describes how an app runs them. In ?play, a program whose main is async runs the same way. Play lists its tokio. Other programs can’t use async yet.
