Commands

You type every command as rawr ... The rawr binary runs run, check, new and doctor itself. It hands other commands to the installed extension that adds them.

Paths

Most commands take an optional path. The path can be a crate directory, its Cargo.toml or a single .rs file. Without a path, rawr looks in the current directory and its parents for a crate whose root file starts with // rawr. The root file is src/main.rs or src/lib.rs. If the root file of the crate doesn’t start with the marker, rawr reports that its first line is not // rawr.

A single file runs with or without the marker. It may hold top-level statements. rawr runs them and then calls fn main.

rawr --help lists the commands. For each installed extension, the help also shows where it was found, which programs it serves and which commands it adds. rawr looks for rawr-<name> binaries next to its own binary first and then on PATH.

Commands of rawr

These come with rawr-cli, which needs Rust 1.95 or newer. rawr-cli also installs cargo-rawr, which forwards to rawr. So cargo rawr run works the same as rawr run.

CommandWhat it does
rawr [run] [path]Checks a program and runs it. run is the default command, so rawr alone runs the crate in the current directory. A program with no dependencies runs once and exits. Then cargo’s errors from cargo check are printed, if there are any. A program with Rust dependencies goes to rawr-import. A program that uses a framework goes to the extension that serves it. rawr-iced serves iced: it opens the app, reloads it on save and runs cargo check in the background.
rawr check [path]Checks a program without running it. It prints Checked and the entry path when the program is valid. It prints the first error when it isn’t. Then it runs cargo check on the crate. It prints cargo check passed or rustc’s errors. It exits with status 1 if either check fails.
rawr new <path>Creates a Cargo crate. It writes Cargo.toml with no dependencies and src/main.rs, which starts with // rawr and holds a small program that prints three lines. rawr run runs it and cargo run builds it natively. It refuses a path that holds files.
rawr new <path> --template <name>Creates a crate from a template that an installed extension offers, and hands the request to that extension. rawr new --help lists the templates. rawr-iced offers iced.
rawr doctor [path]Reports on the environment and the project. It shows where rawr and each extension are and the program it finds, then each extension’s own report. rawr-iced’s report adds the iced revision, the renderer and the manifest.
rawr -h, --helpPrints the help.
rawr -V, --versionPrints the version.

Set RAWR_VERBOSE=1 to see how a program was loaded and which binary ran it.

Commands from extensions

An extension adds programs it serves and commands of its own. You still type them as rawr ...

  • rawr-import runs rawr run and rawr check for programs with Cargo dependencies or native modules. It adds no commands.
  • rawr-iced runs rawr run, rawr check and rawr doctor for programs that use iced. It adds rawr preview, rawr snapshot, rawr mcp, rawr init and rawr cache. Previews and tooling describes them.

Exit status

  • 0 when the command succeeds.
  • 1 when a check fails, when main returns Err or when a snapshot differs. rawr check also exits with status 1 when cargo check fails.
  • 101 when a program panics.

Files rawr writes

  • snapshots/ holds rawr-iced’s stored preview images. Commit it.
  • target/<host>/debug/ holds the compiled crates. rawr run and cargo build share them.
  • target/rawr/ holds rawr’s cached data and the generated runner. cargo clean removes it. The images from the last rawr snapshot --check go in target/rawr/snapshots/.
