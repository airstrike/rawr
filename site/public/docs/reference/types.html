Types

The built-in types, and how values convert between them.

Integers

i8, i16, i32, i64, isize, u8, u16, u32, u64 and usize. Overflow panics, as in a Rust debug build. The wrapping_*, checked_*, saturating_* and overflowing_* methods work. i128 and u128 aren’t supported yet.

let a: u8 = 250;
let b = a.checked_add(10); // None
let c = a.wrapping_add(10); // 4
let d = a.saturating_add(10); // 255
println!("{b:?} {c} {d}");
rawr run integers.rsNone 4 255

Floats

f32 and f64, with methods such as sqrt, powi, floor, round and trunc.

let side = 2.0_f64.sqrt();
let area = side.powi(2).round(); // 2.0
println!("{side} {area:?}");
rawr run sqrt.rs1.4142135623730951 2.0

bool, char and strings

let ok: bool = true;
let initial: char = 'r';
let name: String = String::from("rawr");
let rest: &str = &name[1..];
println!("{ok} {initial} {name} {rest}");
rawr run text.rstrue r rawr awr

Tuples, arrays, slices and Vec

Indexing takes a usize.

let pair = (1, "one");
let zeros = [0; 3];
let v = vec![1, 2, 3, 4];
let middle = &v[1..3];
println!("{pair:?} {zeros:?} {middle:?}");
rawr run tuples.rs(1, "one") [0, 0, 0] [2, 3]

Option and Result

Their usual methods work, and so does the ? operator.

fn first_even(xs: &[i64]) -> Option<i64> {
    let x = xs.iter().find(|x| *x % 2 == 0)?;
    Some(*x * 10)
}

println!("{:?} {:?}", first_even(&[1, 4]), first_even(&[3]));
rawr run option.rsSome(40) None

Box, Rc and Arc

Box<T> and Box<dyn Trait> work. Rc and Arc are imported with use. Fields and methods reach through them, and &Arc<String> passes where &str is expected. Cloning one gives another handle to the same value.

use std::rc::Rc;

let shared = Rc::new(vec![1, 2, 3]);
let other = Rc::clone(&shared);
println!("{}", other.len()); // 3
rawr run rc.rs3

impl Trait

In argument and return position.

fn evens(n: i64) -> impl Iterator<Item = i64> {
    (0..n).filter(|x| x % 2 == 0)
}

println!("{:?}", evens(7).collect::<Vec<_>>());
rawr run impl-iter.rs[0, 2, 4, 6]

Function pointers

fn double(x: i64) -> i64 {
    x * 2
}

let f = double as fn(i64) -> i64;
println!("{}", f(21));
rawr run fn-pointer.rs42

Casts

as converts between numbers. It truncates and saturates as Rust does. Mixing numeric types without a cast fails the check, as in Rust.

let x = 300_i64 as u8; // 44
let y = -1.5_f64 as u32; // 0
let c = 65_u8 as char; // 'A'
println!("{x} {y} {c:?}");
rawr run casts.rs44 0 'A'
