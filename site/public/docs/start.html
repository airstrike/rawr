//Getting started

Getting started

Install what you need. Run a plain program. Then start an iced app and edit it while it runs.

Install

rawr installs from git. There are three things you can install. You only need the ones you use.

The crate

To embed the language in a Rust program, add the crate. It builds on stable Rust 1.95 or newer.

cargo add --git https://github.com/airstrike/rawr rawr

Embedding shows how to compile a script and call its functions.

The rawr command

The rawr command runs rawr programs. It builds on stable Rust too.

cargo install --locked --git https://github.com/airstrike/rawr rawr-cli

The rawr-cli package installs the rawr binary. It also installs cargo-rawr, so cargo rawr run works too. A program without iced runs once and exits. It doesn’t hot reload.

rawr-iced

rawr-iced adds iced support. Install it and rawr hands every program that uses iced to it.

Importing your own Rust crates builds them for the host of the pinned toolchain. It needs a Unix system. It has only been tested on Apple Silicon Macs so far. The rest of rawr-iced should work wherever iced runs. It has only been tested on macOS so far. rawr-iced needs the pinned Rust nightly nightly-2026-07-11 with the rustc-dev and rust-src components. rawr builds iced and your own crates with that toolchain too.

rustup toolchain install nightly-2026-07-11 --component rustc-dev,rust-src
cargo +nightly-2026-07-11 install --locked --git https://github.com/airstrike/rawr rawr-iced-cli
cargo +nightly-2026-07-11 install --locked --git https://github.com/airstrike/rawr rawr-import --features rustc-driver

The rawr-iced-cli package installs rawr-iced. The rawr-import package installs rawr-import-driver in the same directory. The driver reads your Rust crates when a program imports them. rawr looks for rawr-iced next to itself and then on PATH.

cargo install builds iced into rawr-iced, so the install takes a few minutes. After that, an iced app opens in seconds. A project with its own Rust crates compiles them on its first run.

Run rawr doctor to see what is installed and where. Run rawr --help to see which commands each binary provides.

A first program

A plain program is one that doesn’t use iced. Save this as cart.rs. Its first line is // rawr. That line marks it as a rawr file.

cart.rs
// rawr
enum Item {
    Book { price: f64 },
    Coffee { cups: i64 },
}

trait Priced {
    fn price(&self) -> f64;
}

impl Priced for Item {
    fn price(&self) -> f64 {
        match self {
            Item::Book { price } => *price,
            Item::Coffee { cups } => 3.5 * (*cups as f64),
        }
    }
}

fn total(items: &[Item]) -> f64 {
    let mut sum = 0.0;
    for item in items {
        sum += item.price();
    }
    sum
}

fn main() {
    let cart = vec![Item::Book { price: 20.0 }, Item::Coffee { cups: 2 }];
    println!("total: {}", total(&cart));
}
rawr run cart.rstotal: 27

rawr run checks the whole file first. If the check passes, it runs the file’s top-level statements and then fn main. A file can be only statements. It can also be only items and a main, as in Rust. Cargo would not build a file of top-level statements, so keep those to snippets and the playground.

rawr check cart.rs runs the check without running the program. It prints Checked and the path when the file is valid.

Errors

rawr reports one error at a time. Each error has a code, a message and the source span. Where rustc has an error for the same mistake, rawr uses rustc’s code and wording. Change item.price() to item.cost() and run it again:

rawr run cart.rsexit 1
error[E0599]: no method named `cost` found for `Item` in the current scope
 --> cart.rs:23:21-23:25
 23 |         sum += item.cost();
    |                     ^^^^

The program doesn’t start, so nothing is printed before the error.

A first iced app

With rawr-iced installed, rawr new writes a starter crate.

rawr new hello && cd hello && rawr run

rawr new hello creates the hello directory. It holds an ordinary Cargo crate with two files. rawr run opens the app in a window.

hello/Cargo.toml depends on iced from git. The revision is the one rawr-iced is built against. rawr doctor prints it.

Cargo.toml
[package]
name = "hello"
version = "0.1.0"
edition = "2024"

[dependencies]
iced = { git = "https://github.com/iced-rs/iced", rev = "be88873d38544455e26c7a104eb757da2cbbac6b" }

hello/src/main.rs is iced’s own counter example with // rawr as its first line. rawr check accepts it.

src/main.rs
// rawr
use iced::Center;
use iced::widget::{Widget, button, column, text};

pub fn main() -> iced::Result {
    iced::run(Counter::update, Counter::view)
}

#[derive(Default)]
struct Counter {
    value: i64,
}

#[derive(Debug, Clone, Copy)]
enum Message {
    Increment,
    Decrement,
}

impl Counter {
    fn update(&mut self, message: Message) {
        match message {
            Message::Increment => {
                self.value += 1;
            }
            Message::Decrement => {
                self.value -= 1;
            }
        }
    }

    fn view(&self) -> impl Widget<Message> {
        column![
            button("Increment").on_press(Message::Increment),
            text(self.value).size(50),
            button("Decrement").on_press(Message::Decrement)
        ]
        .padding(20)
        .align_x(Center)
    }
}

cargo run builds and runs the same app natively. cargo build --release builds it for release. No interpreter ships with it.

Hot reload

Keep the window open and edit src/main.rs. When you save, rawr run reloads the app in about 0.2 s. The window stays open. The app keeps its state, so the counter keeps its value.

Saving a file marked // rawr never rebuilds native code. Saving a native module or the source of a dependency does. A native module is a file without the marker. rawr run rebuilds the native code and then reloads the app.

rawr run also runs cargo check in the background on launch and after each save. Its errors appear in a card at the top of the window and on stderr. They don’t block the reload.

If a save doesn’t pass the check, the last good version keeps running. The window shows the error until you fix it.
