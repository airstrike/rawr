//Getting started

Getting started

Install what you need. Run a plain program. Then start an iced app and edit it while it runs.

Install

Rawr installs from git. There are three things you can install. You only need the ones you use.

The crate

To embed the language in a Rust program, add the crate. It builds on stable Rust 1.95 or newer.

cargo add --git https://github.com/airstrike/rawr rawr

Embedding shows how to compile a script and call its functions.

The rawr command

The rawr command runs Rawr programs. It builds on stable Rust too.

cargo install --locked --git https://github.com/airstrike/rawr rawr-cli

The rawr-cli package installs the rawr binary. A program without iced runs once and exits. It doesn’t build anything or hot reload.

rawr-iced

rawr-iced adds iced support. Install it and rawr hands every program that uses iced to it.

rawr-iced runs on Apple Silicon Macs for now. It needs the pinned Rust nightly nightly-2026-07-11 with the rustc-dev and rust-src components. Rawr builds iced and your own crates with that toolchain too.

rustup toolchain install nightly-2026-07-11 --component rustc-dev,rust-src
cargo +nightly-2026-07-11 install --locked --git https://github.com/airstrike/rawr rawr-iced-cli
cargo +nightly-2026-07-11 install --locked --git https://github.com/airstrike/rawr rawr-import --features rustc-driver

The rawr-iced-cli package installs rawr-iced. The rawr-import package installs rawr-import-driver in the same directory. The driver reads your Rust crates when a program imports them. rawr looks for rawr-iced next to itself and then on PATH.

cargo install builds iced into rawr-iced, so the install takes a few minutes. After that, an iced app opens in seconds. A project with its own Rust crates compiles them on its first run.

Run rawr doctor to see what is installed and where. Run rawr --help to see which commands each binary provides.

A first program

A plain program is one that doesn’t use iced. Save this as cart.rawr.

cart.rawr
enum Item {
    Book { price: f64 },
    Coffee { cups: i64 },
}

trait Priced {
    fn price(&self) -> f64;
}

impl Priced for Item {
    fn price(&self) -> f64 {
        match self {
            Item::Book { price } => *price,
            Item::Coffee { cups } => 3.5 * (*cups as f64),
        }
    }
}

fn total(items: &[Item]) -> f64 {
    let mut sum = 0.0;
    for item in items {
        sum += item.price();
    }
    sum
}

fn main() {
    let cart = vec![Item::Book { price: 20.0 }, Item::Coffee { cups: 2 }];
    println!("total: {}", total(&cart));
}
rawr run cart.rawrtotal: 27

rawr run checks the whole file first. If the check passes, it runs the file’s top-level statements and then fn main. A file can be only statements. It can also be only items and a main, as in Rust.

rawr check cart.rawr runs the check without running the program. It prints Checked and the path when the file is valid.

Errors

Rawr reports one error at a time. Each error has a code, a message and the source span. Change item.price() to item.cost() and run it again:

rawr run cart.rawrexit 1
error[RAWR-RESOLVE-UNKNOWN-MEMBER]: unknown member `Item::cost`
 --> cart.rawr:22:21
 22 |         sum += item.cost();
    |                     ^

The program doesn’t start, so nothing is printed before the error.

A first iced app

With rawr-iced installed, rawr new writes a starter project.

rawr new hello && cd hello && rawr run

rawr new hello creates the hello directory. Its only file is src/main.rawr. That file is a counter app with two buttons. You don’t need a manifest until you add Rust crates. rawr run opens the app in a window.

This is iced’s own counter example. rawr check accepts it unchanged.

src/main.rawr
use iced::Center;
use iced::widget::{Widget, button, column, text};

pub fn main() -> iced::Result {
    iced::run(Counter::update, Counter::view)
}

#[derive(Default)]
struct Counter {
    value: i64,
}

#[derive(Debug, Clone, Copy)]
enum Message {
    Increment,
    Decrement,
}

impl Counter {
    fn update(&mut self, message: Message) {
        match message {
            Message::Increment => {
                self.value += 1;
            }
            Message::Decrement => {
                self.value -= 1;
            }
        }
    }

    fn view(&self) -> impl Widget<Message> {
        column![
            button("Increment").on_press(Message::Increment),
            text(self.value).size(50),
            button("Decrement").on_press(Message::Decrement)
        ]
        .padding(20)
        .align_x(Center)
    }
}

Hot reload

Keep the window open and edit src/main.rawr. When you save, rawr run reloads the app in about 0.2 s. The window stays open. The app keeps its state, so the counter keeps its value.

Saving a .rawr file never rebuilds native code. Changing one of your own Rust crates does. rawr run rebuilds that crate natively and then reloads the app.

If a save doesn’t pass the check, the last good version keeps running. The window shows the error until you fix it.
