rawr documentation

rawr is a Rust interpreter for your dev builds. These pages are grouped by what you want to do.

What rawr is

rawr interprets Rust. You mark a file in your Cargo crate with // rawr on its first line, and rawr run interprets it while you develop. Cargo compiles the same crate for release.

rawr checks names, types, traits and match arms before anything runs. Its errors use rustc’s codes and point to your source. rawr supports part of Rust. Supported Rust lists what works and what doesn’t.

Two ways to use rawr

The dev loop comes first. Embedding is a separate use, where your app runs Rust scripts with the rawr crate.

UseWhat runsWhat ships in release
The dev looprawr run interprets the files whose first line is // rawr. Cargo compiles native modules and dependencies.Cargo compiles every file. No interpreter ships.
EmbeddingCargo builds your app. Your app runs scripts through the rawr crate.The rawr crate ships, because your app runs scripts.

Extensions add more. rawr-import runs programs with Cargo dependencies. rawr-iced runs iced apps and reloads them when you save.
