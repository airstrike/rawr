Rawr documentation

Rawr is a scripting language that reads like Rust. These pages say what it supports today and how to use it.

What Rawr is

Rawr is a language first. It has Rust’s structs, enums, traits, generics, closures and match. It checks a program before running it. It reports errors the way rustc does. Each error has a code and points at the code at fault.

Rawr code runs on an interpreter. Everything it calls into is native Rust. A Vec or a HashMap in Rawr is backed by native code. An iced widget in Rawr is the real iced widget.

A Rawr program is meant to stay valid Rust. The cart example below compiles with rustc unchanged and prints the same line.

cart.rawrRawr
enum Item {
    Book { price: f64 },
    Coffee { cups: i64 },
}

trait Priced {
    fn price(&self) -> f64;
}

impl Priced for Item {
    fn price(&self) -> f64 {
        match self {
            Item::Book { price } => *price,
            Item::Coffee { cups } => 3.5 * (*cups as f64),
        }
    }
}

fn total(items: &[Item]) -> f64 {
    let mut sum = 0.0;
    for item in items {
        sum += item.price();
    }
    sum
}

fn main() {
    let cart = vec![Item::Book { price: 20.0 }, Item::Coffee { cups: 2 }];
    println!("total: {}", total(&cart));
}
rawr run cart.rawrtotal: 27

The parts

PartWhat it does
rawr crateThe language. Any Rust program can embed it. It builds on stable Rust 1.95 or newer. It knows nothing about windows or widgets.
rawr commandRuns and checks Rawr programs. It builds on stable Rust. A program that doesn’t use iced runs once and exits.
rawr-icedAdds support for iced apps. Install it and the rawr command hands every program that uses iced to it. It reloads a running app in about 0.2 s when you save. It imports your own Rust crates without bindings. It renders #[preview] views to PNG.
?play and the playgroundRun a snippet from Discord or from a browser. A snippet that uses iced replies with its rendered frame. A plain program replies with its output.

The rawr command parses a program once. If the program uses iced, rawr-iced reads that parse and does not parse the file again.

Status

Rawr is pre-alpha. The crate and the rawr command build on stable Rust. They have no platform-specific code. Importing your own Rust crates currently works only on Apple Silicon Macs. The rest of rawr-iced should work wherever iced runs. It has only been tested on macOS so far. rawr-iced follows iced master and pins one Rust nightly. APIs, commands, file formats and error codes will change without notice.

Rawr doesn’t cover all of Rust yet. The language page lists what is missing today. If Rawr rejects valid Rust that it claims to support, that’s a bug. Please report it on GitHub with a small reproduction.
