Requirements and status

What each part of rawr needs, where it has been tested and what is planned.

Status

rawr is pre-alpha. Its API, commands and error codes may change.

rawr supports part of Rust. Supported Rust lists what works today. If rawr runs code with a different result than Rust, or rejects Rust it says it supports, please report it on GitHub with a small reproduction.

Toolchains and platforms

PartNeedsTested on
The rawr crateRust 1.95 or newer.macOS.
The rawr commandRust 1.95 or newer.macOS.
rawr-importA Unix system, and nightly-2026-07-11 with the rustc-dev and rust-src components.Apple Silicon Macs.
rawr-icedThe same as rawr-import, and the one iced revision it is built against. rawr doctor prints that revision.Apple Silicon Macs.
rawr-macrosRust 1.95 or newer. It installs from git and isn’t on crates.io yet.macOS.

Everything installs from the git repository. Get started, Cargo dependencies and rawr-iced give the commands.

rawr-iced supports iced master at revision be88873d. A project on another iced revision is refused with a message.

Planned

These are planned and not built yet:

  • A native module other than the crate root that calls into marked modules.
  • Reload on save for programs that aren’t iced apps. Today they run once and exit.
  • A second UI host, for ratatui, built the way rawr-iced is.
