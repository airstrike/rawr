Troubleshooting

Common errors and what to do about them.

First steps

  • rawr doctor shows where rawr and each extension are installed, and the program it finds.
  • RAWR_VERBOSE=1 rawr run says how the program was loaded and which binary ran it.
  • rawr --help lists the installed extensions and the commands each one adds.

“Its first line is not // rawr”

error[RAWR-ENVIRONMENT-MISSING-SOURCE]: `/home/you/app/src/main.rs` is not a Rawr file. Its first line is not `// rawr`.
  = help: add `// rawr` as the first line of the crate root to run it with Rawr

The crate root must start with // rawr today. Add the line, or run a single file with rawr run path/to/file.rs.

A program needs an extension that isn’t installed

A program with Cargo dependencies needs rawr-import. A program that uses iced needs rawr-iced. rawr run says which one is missing and prints the commands that install it. Cargo dependencies and rawr-iced list them too.

RAWR-ENVIRONMENT-PROJECT-BUILD

A crate with dependencies or native modules needs rust-toolchain.toml and .cargo/config.toml, so that rawr run and cargo build share one build. The error prints both files. Project setup explains them.

rawr’s error or rustc’s?

rawr check prints rawr’s result first: Checked and the path, or one error. Then it prints cargo check passed, or cargo check found and rustc’s errors.

  • An error from rawr alone often means code that rawr doesn’t support yet. The error names the construct. Supported Rust lists the gaps.
  • An error from rustc alone means code that rawr accepts and rustc rejects. That list is on the same page. Fix it for rustc.

The first run takes minutes

With dependencies or iced, the first rawr run compiles them and a runner. Later runs reuse that build in the project’s target/. An edit to a marked file needs no native build.

An iced app doesn’t pick up a save

A save that fails the check leaves the last good version running. The window shows the error and buttons to retry, copy the error or reset the app. Reload an iced app says what a reload keeps.

Reporting a bug

If rawr gives a different result than Rust, or rejects Rust it says it supports, report it on GitHub with a small reproduction.
