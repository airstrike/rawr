Play

The playground runs Rust in your browser. It runs iced code live in the page, or renders it on the server as an image or an animation.

The editor

Ctrl+Enter or Cmd+Enter runs the code. You can pick the theme and a size. The messages box takes one Message expression per line.

The Examples menu lists plain Rust programs in a Rust group, then iced’s own examples in an iced group. A first visit opens the first Rust example. The editor keeps your latest snippet, so /play opens where you left off.

The playground uses the same renderer, limits and allowance as the bot.

Run in browser is the default. rawr loads into the page once the page is up, so it doesn’t hold up the first paint. An iced snippet runs live and updates as you type. A plain program shows its output as the server would. A program with an async fn main runs on the browser’s real clock, so a sleep takes the time it says. Its output shows line by line as it prints. An iced app’s tasks, such as Task::perform with a sleep, run on the same clock. spawn_blocking runs its closure at once, because a page has no threads.

Run on server runs the snippet on rawr’s server. There an iced snippet shows its last frame or a GIF, and an async program runs on a simulated clock, so its sleeps cost no time. A snippet the browser can’t run goes to the server by itself. That happens when rawr doesn’t load and when the browser has no WebGL2 or WebGPU for an iced snippet.

The address

The page’s address keeps what you picked. An example you load adds its name after a #, such as /play#async-tasks or /play#counter. Editing the code drops that name, because the code is no longer the example’s. Picking Run on server adds ?run=server. The browser is the default, so it adds nothing. Opening an address restores both. Picking an example or a mode replaces the address and doesn’t add to the browser’s history.

Share links

Share saves the code and options and gives a link of the form /play/<id>. The link keeps ?run=server when you picked the server. It never has an example’s name, because its code is the share’s. A share’s code also wins over an example’s name in an address. A shared link shows a preview card in Discord and other apps. For an iced snippet the card is its last frame. For a plain program it shows the first line of output. A share that nobody opens for 30 days is deleted.

Snippet shapes

A snippet uses iced when it names the iced crate. It also uses iced when it uses a name from rawr-iced’s prelude without declaring or importing it. Every other snippet is a plain program.

An expression

A bare iced expression renders as a view.

column![text("hi"), button("go")]
(renders a frame)

A view

A function named view with no arguments renders what it returns.

fn view() -> impl Widget<()> {
    row![text("left"), text("right")].spacing(20)
}
(renders a frame)

Only an app takes messages.

An app

A type with fn view(&self) and fn update(&mut self, message) is an app. The snippet can have its own main that calls iced::run or iced::application. Without one, the app boots from State::default(). A main that passes closures to iced::run is an app too. It needs no fn view.

Each msg= is applied in order. Output says when the reply is a PNG or a GIF. An app gets no imports for free, so write its use lines as in a file.

?play light msg=Message::Increment msg=Message::Increment
use iced::widget::{Widget, button, column, text};

#[derive(Default)]
struct Counter {
    value: i64,
}

#[derive(Debug, Clone, Copy)]
enum Message {
    Increment,
}

impl Counter {
    fn update(&mut self, message: Message) {
        match message {
            Message::Increment => self.value += 1,
        }
    }

    fn view(&self) -> impl Widget<Message> {
        column![
            text(self.value).size(40),
            button("Increment").on_press(Message::Increment),
        ]
        .padding(20)
    }
}
(renders a frame)

A plain program

A plain program runs the way rawr run runs a file. The reply is its stdout and stderr in the order it wrote them.

A snippet of statements alone runs as the body of main. If its last expression has no semicolon, its value is printed with {:?}.

let xs = vec![3, 1, 2];
xs.iter().sum::<i64>()
6

The reply shows the exit status when it isn’t 0.

What a snippet can reach

A snippet runs on rawr’s server in a sandbox. It has no files, no environment variables and no network. It can use rawr’s std, iced and a stand-in for tokio, and no other crates. The Play reference lists every limit and every difference from rawr run.
