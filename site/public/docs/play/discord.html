Use rawr in Discord

The ?play bot runs a Rust snippet posted in Discord and replies with the result. It answers in channels where a moderator turned it on.

In Discord

Write ?play on the first line of a message and put the snippet in a code block below it. The fence can be ```rust, ```rs or a bare ```. The bot also answers when ?play is in the fence’s info string, as in ```rust ?play.

Discord
?play 320x200 light msg=Message::Increment
```rust
column![text("hi"), button("go")]
```

The bot runs the first code block in the message. It reads a snippet the way the playground does. A snippet that uses iced gets an image. A plain program gets its output in a text block. An error gets the report that rawr check would print. The report names the snippet play.rs. The bot cuts an error reply to fit Discord’s 2000 characters.

The bot shows Discord’s typing indicator while it runs a snippet. If you edit a message the bot already answered, it runs the snippet again and edits its reply. The bot ignores messages from other bots.

Options

Options go on the ?play line after the command. They are separated by spaces.

OptionMeaning
WxH or size=WxHThe canvas size in logical pixels. Each side can be from 1 to 2048. Without a size the canvas fits the content.
dark, light or theme=..The theme to render with. The default is dark. An app that passes its own function to .theme(..) uses its own theme.
msg=EXPR or message=EXPRA message to apply to an app. Repeat it to apply several in order. The expression can’t contain ;, {, } or #.

Adding the bot to a server

Use the invite link to add the bot to a Discord server you manage. The bot answers only in channels a moderator turns on. It doesn’t answer in direct messages.

Moderators choose the channels with the /play-channel command. It needs the Manage Channels permission in the channel it changes. Its replies are visible only to the moderator who ran it.

CommandWhat it does
/play-channel add [channel]Turns the bot on in a channel. The default is the current channel.
/play-channel remove [channel]Turns the bot off in a channel.
/play-channel listLists the channels where the bot answers.

A thread follows its parent channel. Running /play-channel add in a thread turns the bot on for the parent channel.

The status page shows whether the bot is up. It also counts recent runs.
