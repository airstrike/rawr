Previews and tooling

Render views on their own, check them against stored images and connect a coding agent to the running app.

Previews and snapshots

#[preview] marks a view function to render on its own. A view can have several. The attribute comes from the rawr-macros crate, whose library name is rawr. Add it to [dependencies] in Cargo.toml:

Cargo.toml
rawr-macros = { git = "https://github.com/airstrike/rawr" }

Then write #[rawr::preview(..)], or write use rawr::preview; and then #[preview(..)]. Under cargo the attribute leaves the item as written. rawr reads it itself. Cargo doesn’t warn about a function that only previews use. The crate is not on crates.io yet.

OptionMeaning
name = ".."The preview’s name.
group = ".."Groups previews. rawr preview steps through a group with the arrow keys.
seed = pathA function that builds the state to render, such as Todos::sample. Without it the state is Default.
update = pathThe update function to use in the preview window.
theme = pathA function that returns the Theme to render with.
themes = [..]Several theme functions. Each one gets its own snapshot.
size = (w, h)The canvas size in logical pixels.
snapshot = falseLeaves the preview out of rawr snapshot.
bind = (..)Arguments for a free view function that takes parameters.

rawr preview opens one preview in a window. It takes the preview’s name or group/name. Without a name it opens the last one you picked. The preview window reloads on save as rawr run does.

rawr snapshot --update renders every preview to a PNG under snapshots/. Commit those files. rawr snapshot --check renders them again and compares pixels. It exits with status 1 and names the first changed pixel when an image differs. The new images go under target/rawr/snapshots/ so you can compare them.

rawr snapshot --checkexit 1
Snapshot check found 1 mismatch(es) across 1 artifact(s):

[pixel drift] clock::Clock::view#busy (native)
  expected: snapshots/Clock-6c008925/view/busy/native.png
  actual:   target/rawr/snapshots/Clock-6c008925/view/busy/native.png
  first changed pixel (38, 31): baseline [255, 255, 255, 255], actual [137, 137, 137, 255]

Press Cmd+Shift+S in the window of a running app or preview to save a PNG of it.

Commands from rawr-iced

These need rawr-iced. With rawr-iced installed, it also runs rawr run, rawr check and rawr doctor for programs that use iced.

CommandWhat it does
rawr preview [path] [name]Opens one #[preview] view in a window. name is the preview’s name or group/name. Without a name it opens the last preview you picked. The arrow keys step through a group.
rawr snapshot --update [path]Renders every preview to a PNG under snapshots/ and replaces the stored images.
rawr snapshot --check [path]Renders every preview and compares it with the stored image. It exits with status 1 if any pixel differs. The new images go under target/rawr/snapshots/.
--verboseWith rawr snapshot, prints absolute paths and storage details.
rawr mcpRuns an MCP server on stdio for coding tools such as Claude Code and Codex. Its tools list and render previews, check the project and drive a running window. The window tools take screenshots, click, type, press keys, reset the app and wait for a reload.
rawr init [--claude] [--codex] [path]Registers rawr mcp in the project. --claude writes .mcp.json for Claude Code. --codex writes .codex/config.toml for Codex.
rawr cache cleanRemoves the shared builds that no running process uses.
rawr cache clean --allAlso removes the current project’s target/rawr.

Files

  • snapshots/ holds the stored preview images. Commit it.
  • target/rawr/snapshots/ holds the images from the last rawr snapshot --check.
  • rawr init --claude writes .mcp.json, and rawr init --codex writes .codex/config.toml.
