Testing Scripts
===============

Testing scripts written in Rawr.


Install `rawr-run` Tool
-----------------------

Use the following command to install the `rawr-run` tool:

```sh
cargo install --path . --bin rawr-run
```


How to Run
----------

Run scripts using the `rawr-run` tool:

```sh
rawr-run ./scripts/test_script_to_run.rawr
```

or

```sh
cargo run --bin rawr-run ./scripts/test_script_to_run.rawr
```
